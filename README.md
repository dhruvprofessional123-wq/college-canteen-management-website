# college-canteen-management-website
ABC College Canteen is an offline Python command-line system for viewing menus, managing a cart, calculating bills, and placing orders. It uses dictionaries, functions, loops, conditions, exception handling, and datetime. No database or internet is required.
🍔 ABC College Canteen – Offline Command Line System

A simple Python-based command-line application designed to make college canteen food ordering easier. Students can browse the menu, manage their cart, calculate the total bill, and place orders directly through the terminal.

✨ Features

- 📋 View available food menu
- 🛒 Add items to cart
- 👀 View cart
- ❌ Remove items from cart
- 💰 Calculate total bill
- 🧑‍🎓 Enter student name and roll number
- 🧾 Generate complete order details
- 🕒 Display order date and time
- 🧹 Automatically clear cart after successful order
- 🔌 Works completely offline

🛠️ Technologies & Concepts

- Python
- Dictionaries
- Functions
- Loops
- Conditional Statements
- Exception Handling
- User Input
- "datetime" module
- "os" module

▶️ How to Run

1. Clone the repository

git clone https://github.com/your-username/ABC-College-Canteen.git

2. Open the project folder

cd ABC-College-Canteen

3. Run the program

python canteen.py

💻 How It Works

1. The program displays the available food menu.
2. The student selects food items and quantities.
3. Selected items are added to the cart.
4. The student can view or modify the cart.
5. The total bill is calculated.
6. The student enters their name and roll number.
7. The order is confirmed with complete order details and time.
8. The cart is automatically cleared after successful ordering.

📌 Requirements

- Python 3.x
- No database required
- No internet connection required
- No external libraries required
